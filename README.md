# 🏦 Ari's Python Bank App

A simple console-based banking application built in Python.  
This project was created to practise Python fundamentals such as loops, conditionals, password validation, input handling, and lists.

---

## 🔥 Features

- 🔐 **Password authentication** with limited attempts  
- 💰 **Deposit** money  
- 💸 **Withdrawal** with balance validation  
- 📜 **Transaction history** (stores all deposits and withdrawals)  
- 🧮 Real-time balance updates  
- 📟 Clean and easy-to-use console interface
